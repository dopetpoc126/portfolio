## Design Context

### Users
- **Target Audience**: Tech recruiters, engineering managers, senior software engineers, and fellow developers evaluating Shriyan's software, Android, and 3D WebGL graphics portfolio.
- **Context & Job to be Done**: Visitors want to evaluate technical skill depth, inspect interactive 3D WebGL systems, review past project builds/experience, and easily initiate contact for software roles or engineering collaborations.
- **Emotional Goals**: Evoke awe, high-tech confidence, technical mastery, and interactive delight.

### Brand Personality
- **3-Word Personality**: Futuristic, Precise, High-Performance.
- **Voice & Tone**: Tactical, confident, and systems-focused ("INITIALIZING SYSTEM", "SYSTEMS_BUILDER", "WARP SPEED", "VORTEX MODE").
- **Anti-References**: Plain generic portfolio templates, static corporate white/gray pages, sluggish CSS transitions, or visually flat interfaces.

### Aesthetic Direction
- **Visual Tone**: Cyberpunk Sci-Fi / Tactical HUD interface seamlessly integrated with real-time 3D WebGL shaders and smooth inertia scrolling.
- **Theme**: Strict dark mode anchored by deep void space (`#050505`, `#06070a`), frosted glassmorphic UI panels (`rgba(10, 12, 18, 0.85)` with backdrop blur), tactical corner bracket framing, scanline overlays, and neon glow accents.
- **Color Palette**:
  - **Void / Background**: `#050505`, `#06070a`
  - **Text**: Primary `#ffffff`, Muted `rgba(255, 240, 230, 0.82)`, Subtle `rgba(255, 255, 255, 0.55)`
  - **Accents**: Neon Orange (`#ff4d00`), Electric Cyan (`#00ffcc`), Status Green (`#00ff88`)
- **Typography Stack**:
  - **Headlines / Display**: `'Syne'`, sans-serif (700 / 800 / 900)
  - **Body / Sans**: `'Inter'`, sans-serif (300 / 400 / 600)
  - **HUD / Mono / Code**: `'JetBrains Mono'`, monospace (400 / 700)

### Design Principles
1. **Uncompromised Motion & WebGL Performance**: Prioritize fluid 60fps WebGL particle shaders, smooth Lenis inertia scrolling, and high-impact GSAP warp state transitions.
2. **Tactical Precision & Glassmorphism**: Utilize structured HUD elements (corner brackets, telemetry indicators, scanlines) paired with readable glassmorphic panels so complex 3D graphics enhance rather than hinder content legibility.
3. **High-Contrast Cyber Neon Palette**: Maintain a crisp dark theme built on deep void blacks (`#050505`) and electric accent pairs (`#00ffcc` cyan & `#ff4d00` orange) for immediate visual punch and strong visual hierarchy.
4. **Immersive System Responsiveness**: Treat every user interaction (scrolling, hovering, route transitions, mode switching) as a real-time sci-fi system state response that surprises and delights visitors.
